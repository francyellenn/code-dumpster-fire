## 🚨 O que é este lugar?

Bem-vindo(a) ao **Lixão de Código™**! 

Este repositório é o meu laboratório secreto (e levemente caótico) onde guardo **pequenos projetos, exercícios de cursos, testes rápidos de HTML/CSS/JS** e experimentos que fiz só para ver se a tela não explodia.

## ☣️ Aviso de Segurança (AppSec Alert)
